100% OFFLINE-FIRST & PRIVAT

Kebijakan Privasi Kas-Santri

Berlaku mulai November 2026 • Pengembang: Moch Khoirul Azman

1. Penyimpanan Data Lokal (SQLite Offline-First)

Seluruh data santri, nominal saldo, transaksi harian, tunggakan, mutasi dompet, buku infak, catatan keperluan, nomor WhatsApp wali, serta foto profil santri disimpan 100% secara lokal di dalam basis data SQLite pada perangkat pengurus (dan secara opsional di ruang tersembunyi drive.appdata pada akun Google Drive milik pengurus sendiri). Data keuangan dan data santri pondok Anda tidak pernah dikirim ke server pengembang.

2. Penggunaan Izin Kamera & Galeri

Izin kamera hanya digunakan secara lokal saat pengurus memindai Kode QR Kartu Santri atau mengambil foto profil santri serta logo pondok. Tidak ada gambar atau video yang dikirim ke server eksternal mana pun.

3. Cadangan Privat Google Drive (drive.appdata)

Jika Anda mengaktifkan fitur PRO Cloud Backup Google Drive, aplikasi hanya meminta akses ke ruang tersembunyi khusus aplikasi (scope drive.appdata) pada akun Google milik pondok/pengurus sendiri. Aplikasi tidak dapat melihat atau membaca file pribadi lain di Google Drive Anda.

4. Keamanan PIN, Biometrik, Sinkronisasi Waktu & Metadata Lisensi

PIN keamanan 4–6 digit disimpan dalam bentuk hash kriptografis terenkripsi melalui Android Keystore / EncryptedSharedPreferences. Autentikasi sidik jari ditangani langsung oleh sistem biometrik Android tanpa menyimpan data biometrik mentah di aplikasi.

Untuk menjaga integritas masa aktif lisensi dan informasi versi terbaru aplikasi, aplikasi hanya melakukan sinkronisasi metadata lisensi ringan non-sensitif (ID Perangkat format KS-XXXXXXXX, Nama Pondok, Status Paket Lisensi, dan Versi Aplikasi, serta metadata kontak pengurus khusus pada distribusi Direct APK; versi Google Play Store tidak mengirimkan nama maupun nomor telepon pengurus) dan pembacaan ringan header standar HTTP Date jaringan untuk sinkronisasi waktu anti-manipulasi jam.
